# C# Week 2 — Text RPG

## 구현한 기능

- Player와 Enemy 객체를 이용한 콘솔 기반 전투 시스템 구현
- 이름, HP, 공격력을 Field로 관리
- Constructor를 이용해 객체 생성 시 초기 상태 설정
- Attack, Heal, 상태 확인 등 기능별 Method 분리
- 공격 시 상대 객체의 HP 감소 구현
- 반복문을 이용한 턴 방식 전투 구현
- HP가 0 이하가 되면 전투 종료
- 잘못된 메뉴 입력 처리
- 상속을 이용한 클래스 구조 구현


## 클래스 구조

### Character

Player와 Enemy가 공통으로 사용하는 부모 클래스

- Name
- HP
- AttackPower
- Attack()
- IsDead()

공통 속성과 기능을 관리하여 중복 코드를 줄였다.


### Player

Character를 상속받는 플레이어 클래스

- 플레이어 이름 설정
- 공격 기능 사용
- HP 회복 기능 구현


### Enemy

Character를 상속받는 적 클래스

- 적 이름 설정
- 플레이어 공격 기능 사용


## 상속 적용

Character 클래스를 부모 클래스로 만들고 Player와 Enemy가 Character를 상속받도록 구현했다.

공통적인 HP, 공격력, 공격 기능은 부모 클래스에서 관리하고 각 객체마다 필요한 기능은 자식 클래스에서 확장하는 방식으로 구성했다.


## 배운 점 / 막힌 점

클래스를 역할별로 나누면서 객체가 서로 데이터를 주고받는 방식을 이해할 수 있었다!

상속을 사용하면 공통 기능을 부모 클래스에서 관리하고 자식 클래스에서 확장할 수 있다는 것을 알게 되었다!!
